# COMP2245 Project 2: Fix-It Desk

PHP / MySQL help desk application with Fetch API ticket filters, notes, status updates, and assignment.

## Setup
1. Run `schema.sql` to create and seed the MySQL database (this resets existing demo records).
2. Copy `config.example.php` to `config.php` and configure your local database connection.
3. Start the development server from the repository root: `php -S localhost:8000`.
4. Open `http://localhost:8000/login.php`.

Demo admin login: `admin@fixit.test` / `password123` (requires matching hashed seed data).
